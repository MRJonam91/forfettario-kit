# forfettario-kit MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Verified 2026 parameters, accountant-validated test cases and a static web calculator.

**Architecture:** Same core compiled with `npm run build`; `web/` is a static page importing `dist/core/*.js`; parameters loaded from `data/years/*.json`.

**Tech Stack:** Node ≥ 22.18, TypeScript 5.9, `node:test`, GitHub Pages, vanilla HTML/CSS.

**Spec:** [README.md](../../../README.md), [DATA_SOURCES.md](../../DATA_SOURCES.md)

## Global Constraints
- Core ≤ 1500 lines, zero runtime deps, SPDX `Apache-2.0`.
- Every number shown with its year and the "stima, non consulenza" notice.
- No data leaves the browser (no analytics that record amounts).

## Review Focus
- Revenue 0 or negative → error message, not NaN.
- Unknown activity key → list of valid keys.
- Craftsman with income below the minimale → fixed contribution still due (already tested) and shown as "minimo".
- Year file missing → clear error naming the file.
- Target net unreachable below €100k → message instead of a number above the threshold.
