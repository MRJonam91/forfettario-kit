# Security policy / Sicurezza

**IT** — Segnala vulnerabilità o errori di calcolo con impatto economico **in privato** a fbxmano@gmail.com (oggetto: `[forfettario-kit] security`) oppure da *Security → Report a vulnerability* su GitHub. Risposta entro 7 giorni, finestra di disclosure coordinata di **90 giorni**.

**EN** — Report vulnerabilities or calculation errors with financial impact **privately** to fbxmano@gmail.com (subject: `[forfettario-kit] security`) or via *Security → Report a vulnerability* on GitHub. Reply within 7 days, coordinated disclosure window of **90 days**.
